## **Descripción del Proyecto**

El proyecto consiste en el diseño e implementación de una **Plataforma de Gestión de Alquiler de Vehículos**. La solución contempla:

* Cobertura multiciudad y gestión por sucursales.
* Control de inventario para diversos tipos de vehículos.
* Gestión de perfiles de usuario (ocasionales y empresariales).
* Configuración de esquemas de precios, tarifas y membresías.
* Control de reservas y gestión del ciclo de vida del alquiler.
